# ETF 动量轮动策略回测

宽基 ETF 动量轮动策略的回测脚本，覆盖 **2006-08-18 ~ 2026-08-13** 共 4857 个交易日（20 年）的日频数据，包含两个策略版本与完整的批判性验证流程（消融 / 滚出验证 / 极端行情复盘 / 月度热力图）。

## 策略说明

### v1：动量轮动 + 广度择时（主策略）

1. **动量选股**：每 21 个交易日，计算 6 只股票 ETF 近 10 日动量，动量 > 0（绝对动量过滤）且排名前 2 的各持 50%；
2. **广度择时**：站上 60 日均线的宽基数量 ≤ 一半（全池 6 只时即 ≤3）时，权益仓位收缩到 40%，剩余配国债 ETF；**滞回带 ±2**（广度 ≤ trigger−2 才进防御、≥ trigger+2 才恢复满仓）防阈值附近反复横跳；
3. **指数触发**（000300.SH 真指数）：60 日年化波动 > 25% 或收盘跌破 120 日均线 → 防御——快信号补上广度对急跌（2015 式）反应慢的短板；
4. **信号无未来函数**：T 日收盘定仓位，T+1 日生效；
5. **成本**：佣金单边万1（ETF 无印花税），可配置。

### v2：多因子轮动（豆包文档的忠实实现 + 批判性验证）

120 日动量(60%) + 60 日下行波动率(30%，负向) + 20 日流动性(10%) 截面打分，softmax 梯度权重 + 波动率倒数修正 + 单只上限 40%，三大熊市触发条件控制全局仓位，月末调仓 + 5% 偏离阈值。**结论：该配方在本样本被数据否决**（20 年回测年化仅 2.56%）。

### v3：五资产大类配置轮动（《年化10%回撤20%》文档方案实测）

资产池：000300 指数（沪深300 腿）/ 510880 红利 / 518880 黄金 / 511010 国债 / 510170 商品。MA200 趋势过滤 + 0.5×6M+0.5×12M 混合动量选前 2，月末调仓，0 合格回退国债。**结论：文档"20 年化>9% 且回撤<20%"目标未达成**（实测 8.02% / -47.34%），v1 仍是回撤最优解（-26.51%）。含重要数据审计：510880 前复权污染严重（2016 年前整体不可信，已截断；未截断对照回撤虚化到 -72.87%）。运行：`etf_rotation_v3.py [--walk-forward] [--save-csv]`

## 关键发现（批判性结论）

1. **防御是策略的超额来源**：20 年里五次大熊市段内亏损只有基准的 1/6 ~ 1/2（2008 段 -14.8% vs -84%；2021-24 段 -4.0% vs -50.6%），同时年化 9.68% 跑赢所有基准；
2. **指数触发（真指数）补上快崩盘短板**：60 日波动 >25% 触发把 2015 股灾段亏损从 -36.2% 改善到 -22.1%，全样本回撤 -41.3% → -26.5%、夏普 0.50 → 0.58，收益不减；9 窗滚出对照 4 胜 3 负 2 平；
3. **滞回带（±2）降换手不伤收益**：10 年样本换手 1184% → 799%；20 年样本上同样成立——防阈值附近反复横跳；
4. **滚出验证（9 窗）：自适应选参有害、固定默认稳健**：网格选参前瞻超额 +4.38%、胜率 56%，固定默认 +6.76%、胜率 67%（6/9）——train 上选参是过拟合；超额是条件性的（熊市窗口赚防御钱，2008-09 后的大反弹牛窗口付防御费 -11.8pp）；
5. **跌停约束不构成实际约束**：20 年里卖出腿撞上跌停日的次数为 0——防御时机恰好避开了封板日；2015 的 -22% 亏损来自慢信号，不是被流动性困住；
6. **动量窗口 N 对样本敏感**：3 年样本最优 N=20、10 年样本最优 N=10、20 年样本 N=10 仍优于 N=20/30/60。取两样本均稳的 N=10，但该参数不应被过度信任；
7. **豆包文档多因子配方被数据否决**：因子 IC 近零、下行波动率符号反了、复合 score IC 为负；20 年回测年化仅 2.56%；
8. **混合动量（20/60 日平均）为负优化**：已默认关闭（`--blend` 可开启）。

## 数据说明

- **起始时间不对齐**：159845（2021-03）、588000（2020-11）上市较晚。union 索引下未上市期计 NaN：轮动池自动排除、广度触发按已上市数量归一（≤一半）、等权基准按已上市 ETF 动态等权；停牌日收益按 0 计
- **无复权价**：CSV 为不复权收盘价，ETF 分红（约 1%/年）会轻微低估动量，方向一致
- **沪深300 指数**：无 000300.SH 数据，用 510300 ETF 代理（跟踪误差极小）
- **年化口径**：252 个交易日；无风险利率默认 2%（复利折算日频）

## 局限与声明

- 动量窗口 N、scale 参数均为样本内选择，存在过拟合风险；换手率较高（年单边 ~1180%，万1 佣金下成本可忽略，按 0.1% 滑点计约 1.2%/年）
- 基准未计成本，策略已扣费，对比口径偏保守
- 本仓库仅用于策略研究，不构成任何投资建议
