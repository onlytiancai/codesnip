# 聚宽研究环境兼容性指南

> 本文档记录 `etf_portfolio/` 在聚宽研究环境踩过的所有兼容性坑及解决方案。
> 适用于 `etf_portfolio/` 系列 notebook 和任何准备在聚宽运行的 Python 代码。

## 一、环境基线

| 组件 | 版本 | 备注 |
|------|------|------|
| Python | **3.6.7** | 远低于主流 3.9+，没有内置 dataclasses、match、walrus、内置泛型 |
| pandas | **1.1.5** | `resample("ME")` 还不存在，必须用 `"M"` |
| scipy | **1.2.0** | 较老 |
| scikit-learn | **0.19.2** | `LedoitWolf` 可用 |
| empyrical | < 0.5.x | `sortino_ratio` / `sharpe_ratio` **不接受 `risk_free=` kwarg** |
| matplotlib | 老 | 内部用 `obj[:, None]` 多维索引，老 pandas 不支持，会 `FutureWarning` 且只画一条线 |

> 关键结论：聚宽研究环境是 2020 年左右的版本快照，所有"新版本默认行为"都不能用。

## 二、Python 语法避坑

### 2.1 不要用 `from __future__ import annotations`（Python 3.7+）

聚宽 Python 是 3.6，导入这一行直接 `SyntaxError: future feature annotations is not defined`。

### 2.2 不要用 PEP 604 union 语法 `X | Y`（Python 3.10+）

包括：
- `pd.DataFrame | None` ❌
- `str | Path` ❌
- `Union[date, str]` ✅ 改用 typing.Union
- `Optional[pd.DataFrame]` ✅ 改用 typing.Optional

### 2.3 不要用 PEP 585 内置泛型（Python 3.9+）

- `list[str]` ❌ → `List[str]` ✅
- `dict[str, float]` ❌ → `Dict[str, float]` ✅
- `tuple[X, Y]` ❌ → `Tuple[X, Y]` ✅
- `set[X]` ❌ → `Set[X]` ✅

需要在文件头部 `from typing import List, Dict, Tuple, Set, Optional, Union, Iterable, Any`。

### 2.4 不要用 `@dataclass`（Python 3.7+）

聚宽 3.6 没有内置 `dataclasses` 模块。改成普通 class：

```python
class CandidateETFs(object):
    def __init__(self, kept, dropped, corr_matrix=None):
        self.kept = kept
        self.dropped = dropped
        self.corr_matrix = corr_matrix
```

构造调用不变，仍是 `CandidateETFs(kept=..., dropped=..., ...)`。

### 2.5 不要用 `typing.TypedDict`（Python 3.8+）

`TypedDict` 在 3.8+ 才有，聚宽 3.6 没有。改成普通 class 做 schema 提示（仅作文档用，运行时不影响）：

```python
# ❌ 老版本 ImportError
from typing import TypedDict
class BaselineHolding(TypedDict):
    code: str
    name: str
    weight: float

# ✅ 兼容
class BaselineHolding(object):
    def __init__(self, code, name, weight):
        self.code = code
        self.name = name
        self.weight = weight
```

实际数据仍用普通 dict 存储（`{"code": ..., "name": ..., "weight": ...}`），访问方式不变。

### 2.6 不要用 match/case（Python 3.10+）

### 2.6 walrus `:=` 可以用（3.8+）

### 2.7 f-string `{var=}` 调试语法不行（3.8+ 限定基础，3.13+ 才正式支持）

可以用基础 f-string：`f"x = {x}"`，不要用 `f"{x=}"`。

## 三、pandas 1.1.5 避坑

### 3.1 `resample("ME")` 报错，必须用 `"M"`

```python
# ❌ pandas 2.2+
monthly = prices.resample("ME").last()

# ✅ pandas 1.1.5
monthly = prices.resample("M").last()
```

> 同样地，`"QE"` → `"Q"`，`"YE"` → `"Y"`。

### 3.2 不要用 `DatetimeIndex.freq` 等新属性

老 pandas 的 DatetimeIndex 没有 `.freq`，要用 `pd.infer_freq()`。

## 四、empyrical 老版本 API 差异

### 4.1 `sharpe_ratio` / `sortino_ratio` 不接受 `risk_free` kwarg

```python
# ❌ 老 empyrical 报错
ep.sharpe_ratio(returns, risk_free=0.025)
ep.sortino_ratio(returns, risk_free=0.025)

# ✅ 兼容写法（用 inspect 动态判断）
import inspect

def _accepts_kw(func, kw_name):
    sig = inspect.signature(func)
    return kw_name in sig.parameters

def _call_with_optional_kw(func, returns, rf, kw_name):
    if _accepts_kw(func, kw_name):
        return func(returns, **{kw_name: rf})
    return func(returns)

sharpe  = _call_with_optional_kw(ep.sharpe_ratio, returns, rf, "risk_free")
sortino = _call_with_optional_kw(ep.sortino_ratio, returns, rf, "risk_free")
```

参见 `etf_portfolio/metrics.py`。

### 4.2 `calmar_ratio` 默认月频窗口（不同 empyrical 版本行为不一致）

我们自写的卡玛比率是路径依赖版本（基于训练窗口日收益），不依赖 `ep.calmar_ratio`。优化器中：

```python
def neg_calmar(w, returns_matrix, freq=252):
    port_ret = (returns_matrix.values * w).sum(axis=1)
    nav = np.exp(np.cumsum(port_ret))
    running_max = np.maximum.accumulate(nav)
    dd = (nav - running_max) / running_max
    mdd = float(-dd.min())
    ann_ret = float(port_ret.mean() * freq)
    return -ann_ret / max(mdd, 1e-6)
```

## 五、matplotlib 老版本画图怪行为

### 5.1 多线 plot 只画一条线 + `FutureWarning: obj[:, None]`

**症状**：循环 `for col in df.columns: ax.plot(df.index, df[col])` 时只画出一条线，控制台报：

```
FutureWarning: Support for multi-dimensional indexing (e.g. `obj[:, None]`) is deprecated
```

**根因**：老 matplotlib 内部对 pandas Series 用 `obj[:, None]` 多维索引，老 pandas 不支持。

**修复**：把所有 Series 显式转 numpy 数组，DatetimeIndex 转 datetime 列表：

```python
# ❌ 报错
x_vals = nav_named.index            # Series
y_vals = nav_named[col]             # Series
ax.plot(x_vals, y_vals)

# ✅ 兼容
x_vals = nav_named.index.to_pydatetime()  # list of datetime
y_vals = nav_named[col].values            # numpy ndarray
ax.plot(x_vals, y_vals)
```

### 5.2 不依赖 `pf.create_full_tear_sheet`

`pyfolio 2.x` 与新 `empyrical` 不兼容（已知问题）。本项目只用 `empyrical` 直接算指标 + 自己出图，不调 `pf.*`。

## 七、聚宽研究环境专属注意事项

### 7.1 `from jqdata import *` 必须

聚宽内核 magic：`get_all_securities / get_price / get_security_info / get_index_stocks / finance.run_query` 等都必须先 `from jqdata import *` 才能用。

### 7.2 每个 notebook 顶部必须有 `from jqdata import *`

聚宽重启内存清空，每个 notebook 必须能独立从头跑（不依赖上一个 notebook 的内存对象，只依赖磁盘文件）。

### 7.3 通用模块不能依赖聚宽 magic

`etf_portfolio/*.py` 模块如果用 `get_price` 等聚宽函数，需要在函数体内调用（运行时），不能在 import 时执行。本项目用 `noqa: F821` 标注聚宽 magic 调用。

### 7.4 `finance.run_query` 单次最多 4000 行

不直接影响本项目，但写工具函数时要分页。

### 7.5 `get_price` 单次返回上限

研究环境不严格限速，但建议分批拉（< 100 只 ETF 一次即可）。

## 八、其他常见踩坑

### 8.1 `get_security_info` 返回值

```python
info = get_security_info(code)
# info.start_date, info.end_date, info.display_name, info.name, info.type
# end_date == datetime.date(2200, 1, 1) 表示仍在市
# 注意：info.end_date 是 datetime.date 类型，与 datetime.date(2200, 1, 1) 直接比较
```

### 8.2 复权处理

ETF 用 `fq='pre'`（前复权）：

```python
df = get_price(code, end_date=..., count=..., frequency='daily',
               fields=['close'], skip_paused=False, fq='pre',
               panel=False, fill_paused=True)
```

LOF / 分级基金需要手动处理分红、拆分 → 本项目尽量避开。

### 8.3 `skip_paused=False, fill_paused=True` vs `skip_paused=True`

- `skip_paused=False`：保留停牌日，但 price/volume 都用停牌前收盘价（volume=0）
- `skip_paused=True`：直接跳过停牌日

策略回测建议 `skip_paused=True` + `fq='pre'`，避免噪声。

### 8.4 parquet 缓存路径

`/home/jquser/2026/<项目>/etf_portfolio/outputs/` 是聚宽研究环境的可写路径，跨 session 不持久，**每次重启要重跑**。
