# ETF 组合优化方案（聚宽研究环境）

> **核心理念**：不要找「历史上收益最高的权重」，而是找**这套权重规则，在从未见过的数据上依然有效**。
> 历史最优权重本身毫无实盘价值；**可泛化的配置逻辑**才有价值。

---

## 一、项目目标

按 `基金组合优化参考.md` 的工业级流程，给出 **2–3 个稳健可泛化的 ETF 组合**，外加 3 个硬编码基线作为应急对照。

**两条路线**：

| 路线 | 核心思路 | 适用场景 |
|------|----------|----------|
| **A · 动态滚动优化** | 每月重新求最优权重 → 月度调仓 | 高弹性、研究性 |
| **B · 静态精选池+简单规则** | WFA 跑出反复被赋权的稳健 ETF → 等权/风险平价 | 过拟合风险最低、实盘最稳（主推） |

**3 个硬编码基线**（无需任何优化即可用）：
1. 经典 60/40（沪深300 + 5 年国债）
2. 全天候简化版（A 股 + 海外 + 港股 + 红利 + 债 + 黄金 + 商品）
3. 红利+海外+黄金（进攻型稳健）

## 二、方法论

### 2.1 候选池预过滤（5 年上市 + 5000 万成交 + 0.92 相关去重）

- 上市 ≥ 5 年：覆盖完整牛熊
- 日均成交 > 5000 万元：规避流动性陷阱
- 两两相关系数 > 0.92 保留日均成交更高者：剔除重复标的

### 2.2 三类优化目标

| 目标 | 公式 | 适用 |
|------|------|------|
| 最大夏普 | `(w·μ - rf) / sqrt(w·Σw)` | 单位风险超额收益 |
| 最大卡玛 | `年化收益 / |MDD|` | 收益兼顾回撤控制（用户最关心） |
| 最小方差 | `w·Σw` | 极稳健，但收益低 |

**约束**：单只权重 ∈ [0, 0.30]，Σw = 1。
**协方差矩阵**：Ledoit-Wolf 收缩（对抗协方差矩阵过拟合）。
**均值向量**：EWM 半衰期 120 天（≈ 6 个月）。

### 2.3 滚动样本外（WFA）

- **训练窗口**：60 个月（备选 48）
- **OOS 步长**：1 个月
- **调仓频率**：月度
- **起点**：数据起始 + 60 月
- **终点**：2026-08

每次调仓只用截止到 rebalance 前一日的数据，**严格无未来函数**。

### 2.4 衰减率判定泛化能力

```
衰减率 = (IS Sharpe - OOS Sharpe) / |IS Sharpe|
```

- < 30%：泛化优秀
- 30–60%：尚可
- > 70%：严重过拟合，建议丢弃

### 2.5 对照组

| 对照组 | 实现 |
|--------|------|
| 等权 | `np.ones(n) / n` |
| 风险平价 | Newton 迭代求解 `w_i · (Σw)_i = c` |
| 最小方差 | SLSQP + `objective='minvar'` |
| 经典 60/40 | 硬编码 |

## 六、结果解读

### 6.1 衰减率分布

- **直方图集中在 < 60%**：框架有效
- **衰减率 > 70% 的目标**（如 sharpe）：考虑改用卡玛或 minvar
- **如果三个目标都严重过拟合**：缩小候选池或拉长训练窗口

### 6.2 稳健度评分

| 指标 | 解读 |
|------|------|
| `freq` | 在多少比例的调仓日被赋权 > 1% |
| `avg_weight` | 被赋权时的平均权重 |
| `stability` | 均值/标准差，越高越稳定 |
| `n_obj` | 出现在几个目标的 TOP 权重中 |

**入选规则**：Top 6–10 只，至少包含宽基、红利、债券、黄金中的 3 类。

### 6.3 组合指标对比

主要看：
- **夏普**：单位风险超额收益
- **卡玛**：年化收益 / 最大回撤（实盘最关心）
- **最大回撤**：极端情境损失

**判断标准**：
- 路线 B 应**不显著跑输** 60/40；跑赢则说明框架有增量价值
- 路线 A 弹性高但衰减率更大；波动率高、回撤深的需谨慎

## 七、已知风险与未做之事

1. **MDD 路径依赖**：卡玛优化显式计算训练窗口回撤，不依赖 `ep.calmar_ratio`
2. **未来函数**：训练窗口截止到 rebalance 前一日
3. **复权**：ETF 用 `fq='pre'`；LOF/分级基金未做手工复权
4. **流动性**：5000 万日均是粗筛；实盘需考虑 0.1–0.3% 冲击成本
5. **参数过拟合**：训练窗口只在 {48, 60} 间扫；不连续微调
6. **pyfolio 兼容性**：本框架不依赖 `pf.create_full_tear_sheet`，只用 `empyrical`
7. **未做之事**：
   - 权重噪声扰动测试（参考文档 §三.1）
   - 多时间段压力测试（2015 股灾 / 2018 中美贸易 / 2020 疫情 / 2022 熊市）
   - 跟踪误差 + 换手率指标
   - 网格实验（48 vs 60 月 × 月度 vs 季度）

## 八、下一步建议

实盘前：
1. **跟踪误差**：用 WFA 权重 vs 真实持仓权重计算
2. **调仓成本**：双边 ~0.1% 估算；月度调仓年化拖累 ~1.2%
3. **税收/手续费**：A 股 ETF 免印花税；券商佣金可忽略
4. **现金管理**：预留 5–10% 现金，应对赎回/调仓延迟
5. **定期复盘**：每季度回看衰减率分布是否恶化

## 十、给下一阶段实现者的经验

- **不要直接用 `ep.calmar_ratio` 作优化目标** —— 手写 `neg_calmar(w, returns)`
- **先跑出一个 naive baseline（60/40）再启动 WFA** —— 判断框架正确性
- **保证 WFA ≥ 50 次滚动** —— 衰减率统计有意义
- **`empyrical.calmar_ratio` 默认月频窗口** —— 与日频组合不一致，用自写版本
- **不要在 `01` notebook 调 empyrical** —— 只调 `get_security_info / get_price`；指标放 `02/03`
- **保存中间结果到 parquet/csv** —— 每个 notebook 必须能独立从头跑（聚宽重启内存清空）
- **路线 B 是主交付**：3 个硬编码基线 + 1 个 WFA 跑出的稳健组合，文档明示"这是泛化规则的产物"
