可以。对于你前面这套 **SGI + ROE + Value + Size**，我建议不要采用“打分后直接 Top 100 等权”的方式，而是做成一个**约束优化组合**。

核心思想其实很简单：

> **因子负责告诉你“买谁”，优化器负责决定“买多少”。**

---

## 一、先把整个流程搭起来

建议你的架构是：

```text
原始股票池
   ↓
财务数据清洗 / 防未来函数
   ↓
计算 SGI / ROE / Value / Size
   ↓
因子去极值 + 标准化
   ↓
行业/风格中性化（因子研究阶段）
   ↓
计算综合因子 Score
   ↓
        ┌──────────────┐
        │ 组合优化器    │
        │              │
        │ 最大化 Alpha  │
        │ + 风险约束    │
        │ + 行业约束    │
        │ + 风格约束    │
        │ + 换手约束    │
        └──────────────┘
   ↓
最终权重
   ↓
交易成本/滑点模拟
   ↓
回测
```

真正关键的是中间那个**组合优化器**。

---

# 二、最简单的版本：最大化因子得分

假设你有 1000 只股票。

每只股票都有：

* SGI score
* ROE score
* Value score
* Size score

先得到：

$$
Alpha_i
=

0.3SGI_i+
0.3ROE_i+
0.2Value_i+
0.2Size_i
$$

然后令：$w_i$ 代表股票 $i$ 的投资权重。

最简单的目标：$\max_w \sum_i w_i Alpha_i$

同时要求：$\sum_i w_i=1$

以及：$0\leq w_i\leq2%$

这就已经比“Top 100 等权”先进了一步。

---

# 三、但真正应该加入风险项

因为如果只最大化 Alpha，优化器会非常贪心。

假设：

| 股票 | Alpha |
| -- | ----: |
| A  |   2.5 |
| B  |   2.4 |
| C  |   2.3 |
| …… |    …… |

优化器可能疯狂集中到最高分股票。

所以通常加入风险惩罚：

$
\max_w
\left(
w^T\alpha
-\lambda w^T\Sigma w
\right)
$

其中：

* $\alpha$：预期收益/因子 Alpha
* $w$：股票权重
* $\Sigma$：协方差矩阵
* $\lambda$：风险厌恶系数

这样就变成：

> **在尽量获得因子收益的同时，控制组合风险。**

---

# 四、但对于你的策略，我甚至不建议一开始就上复杂协方差矩阵

因为你的策略是 A 股多因子，而且你目前最需要解决的其实是：

**行业、Size、Beta、换手、集中度。**

所以第一版可以用非常实用的：

## “Alpha + 约束”

目标函数：

$
\max_w
\left[
w^T\alpha
-\lambda|w-w_{old}|^2
\right]
$

这里第二项非常重要。

它表示：

> **不要为了多获得一点 Alpha，就把整个组合换掉。**

这样可以自然控制换手。

---

# 五、行业约束怎么写？

假设有 30 个行业。

令：

$
X_{ij}=
\begin{cases}
1,&股票i属于行业j\\
0,&否则
\end{cases}
$

那么组合在行业 (j) 的权重：

$$
IndustryWeight_j
=
\sum_i X_{ij}w_i
$$

假设基准是沪深300，那么可以要求：

$$
IndustryWeight_j
\in
[Benchmark_j-3\%,Benchmark_j+3\%]
$$

例如：

| 行业   |  基准 |  组合允许 |
| ---- | --: | ----: |
| 银行   | 10% | 7–13% |
| 食品饮料 |  8% | 5–11% |
| 电子   | 12% | 9–15% |
| 医药   |  7% | 4–10% |

这样就不会出现：

> 因子选股突然把 35% 仓位全部塞进电子。

---

# 六、Size 怎么约束？

这个对于你的策略尤其重要。

因为你的模型**本身就想要小盘因子**。

所以不要：

$
SizeExposure=0
$

而是给一个目标区间。

例如定义：

$$
SizeExposure
=

w^T Size
$$

你可以要求：

$$
-1.0
\leq
w^T Size
\leq
-0.3
$$

这里假设 Size score 越小代表市值越小。

也就是说：

> **允许组合有明显的小盘暴露，但不允许无限制地向极小盘集中。**

---

# 七、Beta 也应该加进去

例如：

$
Beta_p=\sum_iw_i\beta_i
$

要求：

$
0.90\leq Beta_p\leq1.05
$

这样你的策略就不会因为 SGI + 小盘恰好同时偏向高 Beta 股票，而变成一个隐形的高风险策略。

---

# 八、单股票约束

非常重要：

$
0\leq w_i\leq2%
$

如果你有 100 只股票：

理论上：

$
100\times2%=200%
$

所以实际权重自然会分散。

你甚至可以做成：

> Top 150 股票 + 单票最大1.5%

这通常比：

> Top 50 + 单票2%

更加稳健。

---

# 九、还可以加“行业内最大权重”

比如：

**单行业 ≤ 15%**

防止因子模型出现系统性偏差。

最终可以形成：

```text
总仓位 = 100%

单票       ≤ 2%
单行业     ≤ 15%

行业偏离基准 ≤ ±3%

Beta       0.90 ~ 1.05

Size       -1.0 ~ -0.3

换手       尽量低
```

这已经是一个相当实用的第一版组合优化器了。

---

# 十、换手约束是非常值得加入的

假设：

* 今天股票 A 权重 1.5%
* 下期模型认为应该是 0%

如果完全按照新模型：

> 直接卖掉。

但这可能没有必要。

可以加入：

$
\lambda\sum_i|w_i-w_i^{old}|
$

或者更容易实现的二次惩罚：

$
\lambda\sum_i(w_i-w_i^{old})^2
$

于是优化器会自动倾向于：

> **如果 Alpha 差异不够大，就不要换仓。**

这对 A 股尤其重要，因为换手率会直接影响实际收益。

---

# 十一、最后就是一个标准的二次规划问题

你的第一版完全可以写成：

$$
\boxed{
\max_w
\quad
\alpha^Tw
-\lambda_1 w^T\Sigma w
-\lambda_2|w-w_{old}|^2
}
$$

subject to：

$$
\sum_iw_i=1
$$

$$
0\leq w_i\leq2%
$$

$$
Industry_j^{min}
\leq
X_j^Tw
\leq
Industry_j^{max}
$$

$$
0.90\leq Beta^Tw\leq1.05
$$

$$
Size^{min}
\leq Size^Tw
\leq Size^{max}
$$

以及：

$$
IndustryWeight_j\leq15%
$$

这就是一个标准的**带约束多因子组合优化**。

# 十四、一个特别重要的设计原则

不要让优化器变成：

> **“用一堆约束把因子 Alpha 全部杀掉。”**

比如你最后发现：

```text
原始多因子组合：
年化 18%
小盘暴露很高
行业偏离很大

加入约束后：
年化 9%
所有风格都接近0
```

这时候不一定是“优化成功”。

很可能是：

> **你把策略真正赚钱的东西也中性掉了。**

所以回测时应该同时画：

**① 原始因子组合收益**

**② 约束后的组合收益**

**③ 行业暴露**

**④ Size 暴露**

**⑤ Beta**

**⑥ 换手率**

**⑦ 交易成本**

然后观察：

> **每增加一层约束，到底损失了多少 Alpha，换来了多少风险下降。**

这比单纯看最终年化收益重要得多。
