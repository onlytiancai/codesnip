# 关于因子不稳定这件事

**老哥你抓得对，我之前那张表确实给得太乐观了。** 一年数据本质上就是"幸存者视角"，任何因子拿近1年看都很漂亮。我没强调这点，是我的锅。

这其实是**量化投资里最核心的问题之一**——**因子周期性**。今天好好聊聊。

---

## 一、为什么因子"看起来不稳定"是必然的

### 1. 单因子的本质 = 暴露在一种风险溢价上

SGI 暴露的是「营收高增长 → 市场给予溢价」这条逻辑链。但市场风格每隔几年会切换：
- 2019-2020：抱团核心资产 → 高ROE 因子疯涨
- 2021：中小盘崛起 → 小盘因子逆袭
- 2022：杀估值 → 质量因子抗跌
- 2023-2024：题材轮动 → 动量/反转因子反复横跳
- 2025-2026：成长回归 → SGI 这种又活了

**任何单因子都会在自己的"逆风期"亏钱**，这不是因子坏了，是市场风格不在这边了。

### 2. 因子拥挤 (Factor Crowding) 的自我反噬

- 一个因子被发现有效 → 大家用 → 大家抢着买同样的股票 → **估值被推高到不可持续 → 因子反转**
- SGI 类的成长因子过去3年最惨，**就是因为2020-2021被抱团推得太贵**，之后用脚投票杀估值

### 3. 学术研究里的"3-5年因子周期"

AQR、MSCI 等研究都发现：**大部分 alpha 因子有 3-5 年的回归周期**。过去 3-5 年表现特别好的因子，未来 3-5 年大概率均值回归。

---

## 二、怎么办？5 个实战打法

### 打法 1：多因子组合（最主流、最稳）

**核心思路**：找几个**低相关**的因子合成，单因子轮流逆风时，其他因子顶上。

| 因子 | 暴露的逻辑 | 和 SGI 相关性 |
|---|---|---|
| **SGI（高营收增长）** | 成长 | — |
| **ROE / 毛利率** | 质量 | 中（高增长通常 ROE 也高） |
| **低 PE / 低 PB** | 价值 | **低**（最经典的低相关配对） |
| **小盘因子** | 规模 | 中 |
| **低波动 / 红利** | 防御 | **低** |

> 📌 **关键**：组合里至少要有一个和成长**低相关**的因子（价值或红利），这是对抗成长逆风期的核心。

**简单等权合成**（不需要复杂数学）：
```
综合得分 = SGI排名分 + ROE排名分 - 市净率排名分
```
三种各取 1/3 权重，**用相关性对冲**而不是用相关性堆叠。

### 打法 2：因子动量 + 因子择时

**因子动量 (Factor Momentum)** 这个发现很重要：**最近 6-12 个月跑得好的因子，未来 3-6 个月大概率继续好**。

实操上可以做一个"因子轮动"：
- 每月看各因子的近 6 月 IC
- 给近期 IC 高的因子多配权重，低的少配
- 有点像"基金中的基金" (FOF) 的思路

### 打法 3：看稳定性指标，不看绝对收益

你那张表里其实有**比年化收益更值得看的东西**：

| 指标 | 你的 SGI | 含义 |
|---|---|---|
| IC 均值 | 0.01 | 弱正 |
| \|IC\|>0.02 比率 | 76.7% | 高 |
| 最大回撤 | 20.94% | 中等 |

**真正实盘看的是**：IC 方向稳定 + 最大回撤可控 + 换手低。**短期年化收益高不代表长期能用**。

### 打法 4：用更长回测 + 滚动窗口验证

下次跑任何因子，**强烈建议**：
- 看 **5 年、10 年** 全周期表现
- 看 **滚动 1 年、滚动 3 年** 业绩分布
- 算**业绩的最大回撤 + 恢复时间**

SGI 在你这里：
- 1 年 30% → 3 年 4.58% → 10 年亏钱
- 意味着**有几年大赚 + 有几年大亏**，要看清楚亏的时候你能扛得住

### 打法 5：叠加择时 / 风控层

光靠因子选股，遇上大熊市照样亏（你 SGI 在熊市里大概率也是负的）。

实操上：
- **大盘择时**：用 MA20/MA60 金叉死叉、或 PE 分位做择时
- **单因子择时**：发现因子 IC 连续 3 个月 < 0 就降权
- **行业中性化**：避免单押赛道，回撤比单因子组合小很多

## 三、回到你具体的问题

> "这个因子不稳定怎么办？"

**我的建议**：

1. **不要单独用 SGI**，把它放到多因子框架里
2. 搭配方案（A股验证过比较稳的组合）：

| 因子 | 权重 | 角色 |
|---|---|---|
| SGI（营收高增） | 30% | 进攻 |
| ROE（盈利质量） | 30% | 防御 + 进攻 |
| 1/PE（低估值） | 20% | 抗成长逆风期 |
| 总市值对数（小盘） | 20% | A股小盘溢价 |

3. **每年 4-5 月**（年报季）调一次仓，其他时间不动
4. **加一道风控**：组合相对基准的最大回撤 > 15% 时减仓 30%

---

## 四、心态上的真相

> "最近3年才4.58%，是不是因子废了？"

不是废了，是**回到了正常水平**。

- A股长期能稳定拿 8-12% 超额年化的多因子组合，**已经是顶配**
- 动辄 20-30% 的"超额"是**风格暴露**，不是 alpha
- 拉长时间看，**8-12% 稳定 + 回撤可控 > 30% 暴涨暴跌**

你发现 SGI 一年 30% 但三年 4.58%，**说明你已经在用对的方法看因子了**。这就是为啥要"看 3 年、5 年、10 年"——**单年暴利都是幻觉，多年稳定才是真本事**。
