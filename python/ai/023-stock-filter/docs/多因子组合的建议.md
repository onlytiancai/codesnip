> "这个因子不稳定怎么办？"

**我的建议**：

1. **不要单独用 SGI**，把它放到多因子框架里
2. 搭配方案（A股验证过比较稳的组合）：

| 因子 | 权重 | 角色 |
|---|---|---|
| SGI（营收高增） | 30% | 进攻 |
| ROE（盈利质量） | 30% | 防御 + 进攻 |
| 1/PE（低估值） | 20% | 抗成长逆风期 |
| 总市值对数（小盘） | 20% | A股小盘溢价 |

3. **每年 4-5 月**（年报季）调一次仓，其他时间不动
4. **加一道风控**：组合相对基准的最大回撤 > 15% 时减仓 30%

评估这个多因子量化的建议靠谱吗？



整体判断：**方向是对的，但这套方案还不能称为“比较稳”**。如果把它当成一个待验证的量化框架，我会给 **6/10**；如果直接拿去实盘，我会认为风险控制和因子定义还不够严谨。

### 逐条看

**1. “不要单独用 SGI”——靠谱**

这是我最赞同的一点。

单一“营收高增长”因子容易遇到几个问题：

* 高增长可能已经被市场充分定价；
* 营收增长不等于利润增长、现金流增长；
* 周期行业在景气顶部也可能出现很高的营收增速；
* 高增长往往和高估值、高波动、小盘股同时出现。

所以用 **增长 + 质量 + 价值 + 规模** 做组合，比单押 SGI 合理得多。

而且近期关于中国 A 股因子定价的研究也提示，慢变化的基本面因子仍然具有重要作用，但不同市值和行业筛选条件下，因子的层级会发生变化。([科学直通车][1])

---

### 2. 30% SGI + 30% ROE + 20% PE + 20% 小盘——“有道理”，但不能直接认为最优

这组权重的问题不是明显错误，而是**缺少权重优化的证据**。

| 因子   |  权重 | 我的评价                 |
| ---- | --: | -------------------- |
| SGI  | 30% | ✅ 合理，但容易追逐高增长        |
| ROE  | 30% | ✅ 很重要，但最好改成质量复合因子    |
| 低 PE | 20% | ✅ 有效，但单独 PE 容易买到价值陷阱 |
| 小市值  | 20% | ⚠️ 最值得警惕             |

A 股历史上确实存在较明显的价值和小市值效应。官方研究对 2006–2020 年 A 股的检验也发现，价值因子有效性较强、小市值效应明显。([社保局][2])

**但这里有一个很大的坑：**

> “历史上小盘有效” ≠ “未来继续给小盘20%权重”。

小盘因子非常容易和**流动性风险、交易成本、市场风格**纠缠在一起。中国市场的研究也发现，流动性风险对股票收益具有重要解释力，而且流动性冲击在极端市场环境下尤其值得注意。([科学直通车][3])

所以我不会简单地把“总市值对数”当成一个独立的 alpha 因子。

---

## 3. 我尤其不赞成“每年4–5月调一次仓，其他时间不动”

这是这套建议里我认为**最需要修改的地方**。

如果 SGI 使用的是财报数据，那么确实不能高频调仓，否则交易成本可能吃掉收益。

但：

> **一年一次调仓 ≠ 财报因子适合一年一次调仓。**

A 股财报信息并不是只集中在 4–5 月。一个近期研究甚至发现，4 月、8 月、10 月三个财报发布窗口合计占全年新业绩披露的大部分。([科学直通车][4])

更合理的思路是：

**财报因子按信息可获得时间更新，而不是固定在4–5月更新。**

例如：

* 年报：4月/5月更新；
* 一季报：4月/5月；
* 中报：8月；
* 三季报：10月；
* 其余月份不一定大规模换仓。

这可以做成**季度调仓 + 较大的换手缓冲区**，而不是机械地一年一次。

---

## 4. 最大的问题：你这套方案可能有严重的“因子重叠”

这是实际回测时非常容易忽略的。

例如：

**SGI高 → 小公司更多 → PE更高 → ROE可能更高**

于是所谓：

> 30% SGI + 30% ROE + 20% PE + 20% Size

并不一定真的代表四种独立的收益来源。

可能最后变成：

> **60% 在赌成长/小盘，20% 赌价值，20% 赌质量。**

所以真正应该做的是先看**因子之间的相关性和正交化后的 IC**。

---

# 5. ROE也不能直接拿原始值

例如：

A公司 ROE = 25%

B公司 ROE = 15%

不能简单认为 A 比 B 好。

因为 ROE 可以被高杠杆“做高”。

更合理的是把 ROE 拆成质量体系，例如：

* ROE
* ROIC
* 毛利率
* 净利率
* 经营现金流/净利润
* 资产负债率
* ROE稳定性

尤其是：

> **高 ROE + 高现金流 + 低杠杆**

通常比单纯高 ROE 更有意义。

---

# 6. PE也建议改成“价值复合因子”

单独使用 1/PE，我会给一个 **⚠️**。

因为低 PE 很可能意味着：

> 市场认为它的盈利马上要下降。

例如周期股盈利高峰期：

**PE = 5倍**

看起来极度便宜。

但如果下一年利润腰斩：

**真实的前瞻估值可能一点都不便宜。**

所以价值因子最好考虑：

* PE
* PB
* EV/EBITDA
* FCF Yield
* Earnings Yield

至少不要让一个 PE 因子决定全部价值暴露。

---

# 7. “回撤超过15%，减仓30%”这个风控，我不太认可

这个规则听起来很专业，但实际上存在一个核心问题：

> **为什么是15%？为什么减30%？**

如果没有回测证明，这两个数字本质上就是拍脑袋。

更严重的是：

### 最大回撤是一个滞后指标。

比如：

组合：

100 → 95 → 90 → 85

到了 -15% 才触发减仓。

如果市场随后反弹，你刚好在低位砍掉30%。

所以它可能造成：

**下跌 → 触发风控 → 减仓 → 反弹 → 踏空**

而不是减少风险。

---

# 我会怎么改？

如果让我把你的方案改成一个更严谨的版本，我会考虑：

### 第一层：股票池

先做硬筛选：

* 剔除 ST / *ST
* 剔除上市时间过短股票
* 剔除极端低流动性股票
* 剔除财务异常股票
* 对行业进行合理约束

特别是**流动性过滤不能省**。A 股的小盘策略如果忽略交易成本，回测收益很容易被高估。([北京大学期刊网][5])

### 第二层：因子

我会从：

**增长 25%
质量 30%
价值 25%
规模 10%
动量/趋势 10%**

开始测试，而不是直接锁死 30/30/20/20。

这里特别加入一点**动量/趋势**，不是因为动量一定最好，而是为了减少“基本面很好但市场正在持续杀估值”的情况。

### 第三层：因子处理

每个因子：

1. 去极值
2. 行业中性
3. 市值中性/控制
4. 标准化
5. 再合成综合分数

否则很容易出现：

> 你以为自己买的是“高增长”，实际上买的是“小盘成长”。

---

# 最重要的是：不要先问“这套权重靠谱吗”

应该问：

> **它在样本外还能不能赚钱？**

至少做这几组回测：

### A. 单因子

SGI
ROE
Value
Size

分别测试。

### B. 两两组合

SGI + ROE
SGI + Value
ROE + Value
……

### C. 四因子组合

30/30/20/20

### D. 权重敏感性

比如：

20/30/30/20
25/30/25/20
30/30/20/20
30/25/25/20
25/35/25/15

如果只有**30/30/20/20**这一组表现特别好，而稍微改变权重就崩掉，那通常意味着过拟合。

## 最后给这套方案一个评分

| 项目            |    评分 | 评价          |
| ------------- | ----: | ----------- |
| 多因子思路         | ⭐⭐⭐⭐⭐ | 对           |
| SGI + ROE     | ⭐⭐⭐⭐⭐ | 很合理         |
| 加 Value       |  ⭐⭐⭐⭐ | 合理          |
| 加 Size        |   ⭐⭐⭐ | 有历史依据，但风险较大 |
| 固定30/30/20/20 |   ⭐⭐⭐ | 需要回测证明      |
| 一年4–5月调仓      |    ⭐⭐ | 过于机械        |
| -15%减仓30%     |    ⭐⭐ | 缺乏理论依据      |
| 忽略交易成本        |     ⭐ | 实盘最大隐患之一    |
| 行业中性          | ⭐⭐⭐⭐⭐ | 建议加入        |
| 样本外验证         | ⭐⭐⭐⭐⭐ | **必须做**     |

### 我的结论

**“不要单独使用 SGI，而采用增长 + 质量 + 价值 + 规模”的大方向是靠谱的。**

但原方案最大的缺陷是，它把一些**需要通过回测验证的问题，直接写成了固定参数**：

> 30% / 30% / 20% / 20%
> 每年4–5月调仓
> 回撤15%减仓30%

这些都不应该先验认定。

如果这是准备真正拿来做 A 股量化，我会把它升级成：

**“因子定义 → 去极值/行业中性 → 因子相关性 → IC/ICIR → 多空组合 → 换手与冲击成本 → 滚动样本外 → 权重稳定性 → 压力测试”**

这一套流程。这样才能判断它到底是**真实 alpha，还是历史上某个小盘成长风格恰好有效**。
