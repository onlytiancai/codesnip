如何做风格中性化和行业中性化，是在因子挖掘时做，还是多因子选股后针对组合做中性化？

**两处都要做，但目的不同。**如果你是在做真正的多因子选股，我建议采用：

> **因子层面中性化 + 组合层面约束/再中性化**

而不是二选一。

### 1. 因子挖掘阶段：先做“因子中性化”

这是为了回答一个最重要的问题：

> **这个因子本身到底有没有 alpha，还是只是偷偷携带了行业/市值风格？**

例如你发现 SGI 的 IC 很高，但进一步发现：

* SGI 高的股票主要是小盘股；
* SGI 高的股票主要集中在某几个行业。

那么你看到的 SGI alpha，可能其实是：

**小盘因子 + 行业因子 → SGI 看起来有效。**

所以在因子研究阶段，建议对原始因子做：

**行业中性 + 市值中性**

典型做法是横截面回归：

$$
SGI_i=\alpha+\beta_1\ln(MV_i)+\sum_j\gamma_j Industry_{ij}+\epsilon_i
$$

然后拿残差：

$$
SGI^{neutral}_i=\epsilon_i
$$

作为真正用于研究的 SGI。

这样你测试的就是：

> **在控制市值和行业之后，SGI 剩下的部分是否还能预测未来收益？**

这一步非常重要。

---

# 2. 多因子合成之后：还要做一次组合层面的中性化

原因完全不同。

假设你已经把：

* SGI
* ROE
* Value
* Size

都做了行业/市值中性化。

然后综合：

$$
Score=0.3SGI+0.3ROE+0.2Value+0.2Size
$$

选出 Top 100。

**这时候你的最终组合仍然可能重新产生行业和风格暴露。**

原因是：

> 因子中性 ≠ 组合中性。

例如四个因子分别都是行业中性的，但是综合排序以后，恰好：

* 银行股得分普遍高；
* 小盘股得分普遍高；
* 高 beta 股票得分普遍高。

最后你的 Top 100 仍然可能变成一个明显的：

**银行 + 小盘 + 高 beta**

组合。

所以组合构建阶段还需要约束。

---

# 3. 两个阶段的目的可以这样理解

| 阶段    | 做什么        | 目的              |
| ----- | ---------- | --------------- |
| 因子挖掘  | 因子行业/市值中性化 | 判断因子是否真正有 alpha |
| 多因子合成 | 各因子标准化、合成  | 得到综合评分          |
| 组合构建  | 行业/风格暴露约束  | 控制最终组合风险        |
| 回测    | 检查实际暴露     | 防止中性化失效         |

所以我推荐的流程是：

**原始因子 → 因子中性化 → 单因子检验 → 多因子合成 → 组合优化 → 组合中性化/约束 → 回测**

---

# 4. 但是有一个非常重要的例外：Size 因子

你前面这套策略里有：

> **20% 总市值对数（小盘）**

这里就不能简单地说：

> “把所有因子都做市值中性化。”

因为你**本来就是想赚小盘因子的 alpha**。

如果你把最终组合严格做成市值中性：

> 小盘暴露 ≈ 0

那你等于把自己最想要的 Size factor 给消掉了。

所以这里应该区分：

### 你想要的风险暴露

例如：

* 行业：中性
* Beta：中性
* 小盘：**主动暴露**
* SGI：主动暴露
* ROE：主动暴露
* Value：主动暴露

那么组合优化时就应该明确规定：

> **Size 暴露允许偏离基准，但不能超过某个范围。**

比如：

**组合 Size z-score ≤ -0.5**

而不是：

**Size z-score = 0**

---

# 5. 我更推荐“约束”而不是机械“完全中性”

例如你的 A 股策略，可以设计成：

### 行业

相对基准：

> 行业权重偏离 ≤ ±3%

### 市值

允许：

> 小盘暴露 = 基准 - 0.3～0.8 个标准差

### Beta

控制在：

> 0.95～1.05

### 单票

例如：

> ≤ 2%

### 行业

例如：

> ≤ 15%

这样比“全部归零”更合理。

因为**中性化本身不是目的**。

真正的目的应该是：

> **把你不想承担的风险控制掉，把你明确想赚的因子暴露留下来。**

---

# 6. 还有一个容易踩的大坑：不要“过度中性化”

假设你发现：

> SGI 和小盘高度相关。

然后你把 SGI 做市值中性化。

结果 SGI 的 IC 从：

**0.045 → 0.012**

这时候不能简单得出：

> “SGI 没用。”

它可能意味着：

> **SGI 的收益很大一部分就是通过小盘风格实现的。**

这其实是一个非常有价值的研究结论。

你应该进一步拆解：

**SGI 原始收益**

= **纯 SGI alpha**

* **Size exposure**

* **Industry exposure**

然后决定：

> 我到底要不要这部分 Size exposure？

这比简单地把它全部消掉更有意义。

你的四个因子：

**SGI 30%
ROE 30%
Value 20%
Size 20%**

我会采用：

### 因子研究

**SGI**

**ROE**

---

### 多因子合成

先把各因子变成可比较的标准分数，例如：

$$
Score_i
=0.3Z(SGI_i)
+0.3Z(ROE_i)
+0.2Z(Value_i)
+0.2Z(Size_i)
$$

然后进行股票筛选。

---

### 最终组合

再做一次组合优化：

**目标：最大化综合因子分数**

同时约束：

* 行业偏离
* Beta
* 单票权重
* 换手
* 流动性
* 最大小盘暴露

而不是简单地把所有暴露都压成 0。

---

## 一句话总结

**因子层面中性化，是为了研究“这个因子到底有没有独立 alpha”；组合层面中性化，是为了控制“最终投资组合承担了什么风险”。**

所以对于你这个策略，我最推荐：

> **因子研究阶段：行业中性 + 市值中性，识别纯 alpha。**
> **组合构建阶段：行业严格约束 + 风格软约束 + 保留你主动想要的 Size 暴露。**

尤其是你把 **Size 本身作为20%因子** 的情况下，**绝对不要在最终组合里再把 Size 完全中性掉**，否则策略逻辑会自相矛盾。
