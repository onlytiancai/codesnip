# MiniLang

用 C 语言写的一个小型解释型语言，零依赖（只用标准 C 和 `libm`）。

它既是**一个能跑的解释器**，也是**一套 13 步的教程**——你可以从零开始，一步步把它实现出来。

```
let x = 10;
print("x = {x}\n");
```

## 教程：从零实现 MiniLang（13 步）

这是本项目的主线。**每一步都建立在上一步的代码之上**，两步之间的 `diff` 就是"这一步要敲的东西"——
所以你不需要"参考一个完整实现自己研究"，只需要照着 `00N/README.md` 里的 diff 一段一段敲进去。

| [002](002/README.md) | 表达式语法分析 → AST | 能把表达式变成一棵抽象语法树 |
| [003](003/README.md) | AST 求值器（算术） | 能算出 `1 + 2 * 3` 的值 |
| [004](004/README.md) | 比较与逻辑运算 | 支持 `== != < <= > >= && \|\| !`，含短路求值 |
| [005](005/README.md) | 语句 / let / 作用域 | 真正能执行程序：变量、赋值、块级作用域 |
| [006](006/README.md) | if / else | 条件分支 |
| [007](007/README.md) | for 循环 | `for (init; cond; update)`，带死循环保护 |
| [008](008/README.md) | 内置函数 | 表驱动的 `abs/round/sqrt/floor/ceil/pow/min/max` |
| [009](009/README.md) | print 与字符串模板 | `print("x = {x}\n")` |

每一步的目录里都有：

- `README.md` —— 详细讲解：本步目标、涉及的知识点、**要加哪些代码（真实 diff）**、测试用例、易错点、自测题

- `run.sh` —— 一键验证：`./run.sh`

```bash

```

### 教程里的"只加不改"约定

整套教程只有**三处**允许修改已有代码，其余全是"只加不改"——这样相邻两步的 diff 几乎全是新增行：

1. 第 9 步给 `print` 插入字符串模板分支、给算术运算插入字符串类型校验；
2. 第 10 步把函数调用分支从"一条路"改成"内置函数 / 用户函数两条路"；
3. 第 13 步整体搬家（去 `static`、加头文件，函数体一字不改）。

靠这个约定，第 3 步就把 `Value` 的字符串字段预留好了，第 5 步就把 `Flow` 定型好了——
所以第 9 步加字符串、第 11 步加 `return` 的时候，**一个函数签名都不用改**。

## 编译与运行

```bash
cc -std=c11 -Wall -Wextra -O2 minilang.c -lm -o minilang
./minilang demo.ml
```

输出：

```
sum = 15
factorial = 120
sqrt = 9
```

程序有三种模式：

```bash
./minilang demo.ml            # 默认，等同于 run
./minilang demo.ml run        # 解释执行
./minilang demo.ml tokens     # 只做词法分析，打印 token 列表
./minilang demo.ml ast        # 只做语法分析，打印语法树
```

多文件版本（见 [013](013/README.md)）：

```bash
cd 013 && make && ./minilang demo.ml
```

## 语言说明

### 支持的语法

| 功能 | 示例 |
| --- | --- |
| 整数和小数 | `let a = 10;`、`let b = 3.14;` |
| 四则运算与取余 | `let c = a + b * 2;`、`a % b` |
| 比较与逻辑 | `a > b`、`a == b`、`a && b`、`!a` |
| 变量定义与赋值 | `let x = 1;`、`x = x + 1;` |
| 内置函数 | `abs(-3)`、`sqrt(16)`、`round(3.6)`、`pow(2, 10)`、`min(1, 2)`、`max(1, 2)`、`floor(1.5)`、`ceil(1.5)` |
| 条件语句 | `if (a > 10) { ... } else { ... }` |
| 循环 | `for (let i = 0; i < 10; i = i + 1) { ... }` |
| 函数定义与调用 | `fn add(a, b) { return a + b; }` |
| 递归 | 函数可以调用自己 |
| 打印 | `print("结果是 {c}\n");` |

每条普通语句以 `;` 结尾；`if` / `for` / `fn` 的代码块后面**不需要**分号。

### 数值与真值

- 所有数字内部都用 `double` 存储，所以 `10 / 4` 的结果是 `2.5`。
- 输出统一用 `%.15g`：`15` 打印成 `15` 而不是 `15.000000`，`3.5` 打印成 `3.5`。
- 真值规则：**0 是假，非 0 是真**。比较运算的结果是 `0` 或 `1`。
- `&&` 和 `||` **短路**：`0 && (1/0)` 不会报除零错误。
- 变量只能是数字。字符串只出现在 `print` 的参数里，不能存进变量、也不能参与运算。

### 作用域

```
全局作用域          let x = 1;
  └─ 块作用域       { let x = 2; }   ← 内层的 x 遮蔽外层的 x
```

- `{ }` 里的 `let` 只在块内可见，出了块就没了。
- 同名时**内层遮蔽外层**；查找变量从内往外找，找到第一个就用。
- 同一个作用域里重复 `let` 同一个名字会报错。
- 函数里**赋值**（`x = ...`）会改到外层的变量；函数里的 `let` 是新的局部变量。

### 字符串模板

`print` 的参数如果是一个字符串，就按模板渲染：`{变量名}` 会被替换成变量的值。

```
let x = 10;
print("x = {x}\n");     →  x = 10
```

模板里**只支持标识符**。`print("{sqrt(81)}")` 会报"未定义变量 'sqrt(81)'"——
因为模板不是表达式求值，只是查变量。先把结果赋给变量再打印：

```
let r = sqrt(81);
print("sqrt = {r}\n");
```

### 错误提示

出错时会在标准错误输出上打印**类型 + 行列号 + 原因**，并把出错的那一行源码和一个 `^` 指示符一起打出来：

```
错误 [3:13]: 未定义变量 'price'
   3 | let z = x + price;
     |             ^
```

| 类别 | 例子 |
| --- | --- |
| 词法错误 | `无法识别字符 '@'`、`字符串缺少结束引号` |
| 语法错误 | `语法错误：此处需要数字、变量、函数调用或括号表达式` |
| 未定义变量 | `未定义变量 'price'`、`不能给未定义变量 'y' 赋值` |
| 重复定义 | `变量 'x' 在当前作用域中已定义`、`函数 'f' 重复定义` |
| 类型不匹配 | `变量目前只支持数字类型`、`算术和比较运算只能用于数字` |
| 参数错误 | `函数 'abs' 参数数量错误：需要 1 个，实际 2 个`、`函数 'add' 需要 2 个参数，实际传入 1 个` |
| 运行时错误 | `除数不能为 0`、`sqrt 参数不能为负数` |
| 保护机制 | `函数递归深度超过 128`、`循环执行超过安全上限 1000000 步` |

出错时程序以**退出码 1** 结束；命令行参数用错时退出码是 **2**。

### 已知限制

- **模板只支持 `{标识符}`**，不能在模板里写表达式。
- **变量只能是数字**，字符串不能存进变量。
- **遇到第一个错误就停**，不会收集多个错误。
- **`for` 的更新部分只支持 `i = 表达式`**，不支持 `i++`。
- **只有顶层的 `fn` 会被登记**，嵌在块里的函数定义调用时会报"未知函数"。
- **`print` 不自动换行**，需要换行请在字符串里写 `\n`。
- **`round` 是向 +∞ 方向四舍五入**（`floor(x + 0.5)`），所以 `round(-2.5)` 是 `-2`，和 C 标准库的 `round()` 不一样。
- **有规模上限**：`Token` 20000 个、AST 节点 20000 个、单个作用域 2048 个变量、函数参数 32 个、函数 256 个、递归 128 层、循环 100 万步。
- **静态内存占用大**：`Token` 里带 4 KB 的文本缓冲，2 万个就是约 80 MB 的静态内存（`Node` 同理）。教学版选择了简单，改造思路见 [013](013/README.md) 的路线图。

## 实现要点

- **纯 C11**，不依赖任何第三方库，只需要 `libm`（编译时加 `-lm`）。
- **词法分析 → 语法分析 → 解释执行**三段式，语法分析用递归下降生成 AST，执行是树遍历。
- **表达式和语句分成两个函数**：`eval()` 算表达式，`exec()` 执行语句。
- **控制流用 `Flow` 结构传递**：`{ int returned; Value value; }`，`return` 的值一层层往上冒泡。
- **作用域是一条链表**：`Env` 里有 `parent` 指针，变量表是按需增长的动态数组。
- **内置函数是表驱动的**：`Builtin` 结构 + 函数指针数组 + 名字查找。
